Rudra Labs is an IT company building artificial intelligence and software
products for people and businesses. We work on the unglamorous problem of
friction — the repeated steps, the clumsy interfaces, the tasks that take five
minutes longer than they should — and we build software that removes it.

## What we do

**Artificial intelligence** — Speech recognition, natural language interfaces
and assistants that understand how people actually talk, including the mix of
languages most of the world uses every day.

**Product engineering** — Desktop, web and backend software, built to be
maintained rather than demoed.

**Automation** — Tools that take repetitive work off people's hands so they can
spend their time on the part that needs judgement.

## Products

### 🎙 Black Voice

An offline-first voice assistant for Linux that understands Hindi, English and
Hinglish — because most people speak a mixture, and software should keep up.

Talk to your computer instead of typing at it: open applications, control the
system, find files, set reminders, run commands and ask questions. Speech
recognition runs locally on your own machine, so it works without an internet
connection and your voice stays with you.

**[→ Repository](https://github.com/rudralabs/black-voice)**

## How we build

**People first.** Technology is judged by whether it saves someone time or
effort. If it does not, it is decoration.

**Works everywhere.** Real users run old laptops, patchy connections and
whichever operating system they already have. We build for that, not for a
reference machine.

**Private by default.** Data stays on the user's device unless there is a clear
reason for it to leave, and the user agrees to it.

**Honest engineering.** We ship what is finished, say what is not, and write
software we are willing to maintain.
